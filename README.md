# Mathematical Methods in Deep Learning — Study Resources

A local collection of notebook examples accompanying **Math and Architectures of Deep Learning**.

## Purpose

Study the mathematical foundations behind model development: linear algebra, gradients, optimization, convolution, probability, and neural-network architectures.
